# linksforobjets

Colección personal de enlaces a productos que estoy evaluando o quiero comprar. No es código: cada archivo es una lista de URLs en texto plano, agrupada por tipo de objeto y, dentro de cada archivo, por tienda o modelo.

| Archivo | Contenido |
| --- | --- |
| `Cars` | Repuestos y accesorios para auto (Suzuki Sidekick, Hyundai Veloster) en Amazon, eBay e iPartes |
| `Cemaco` | Artículos para el hogar en Cemaco (salas, ventiladores, ropa de cama, herramientas, etc.) |
| `Chairs Gaming` | Sillas gaming en Imeqmo, con la opción preferida marcada |
| `Monitors` | Monitores y soportes en Kemik y Click (Guatemala) |

Los archivos no tienen extensión y se editan a mano. Las URLs pueden caducar o cambiar de precio con el tiempo.
